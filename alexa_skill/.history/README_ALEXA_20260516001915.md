# Skill de Alexa — Cine Inteligente

Práctica de IA Agéntica · Agentes Inteligentes


Usa **OMDb API** para consultar datos de películas, en lugar de hacer scraping directo de IMDb. Esto hace que la solución sea más estable para AWS Lambda y evita problemas frecuentes de bloqueo al scrapear IMDb directamente.

---

## Descripción

Skill de Amazon Alexa que permite consultar información de películas por voz.

El usuario puede preguntar en español por:

- nota IMDb
- número de votos
- sinopsis
- director
- duración
- género
- información completa de una película

Los datos se obtienen de la API de **OMDb** y se cachean para evitar consultas repetidas innecesarias, tal y como pide el enunciado de la práctica.

## Funcionamiento general

El flujo de la skill es el siguiente:

```text
Usuario habla con Alexa
        |
        v
Alexa detecta el intent y el título de la película
        |
        v
lambda_function.py recibe la petición
        |
        v
cache.py comprueba si la película está en caché
        |
        v
Si no está en caché, imdb_scraper.py consulta OMDb API
        |
        v
La respuesta se normaliza y se devuelve a Alexa
        |
        v
Alexa responde por voz al usuario
```

## Requisitos previos

### 1. API key de OMDb

Necesitas una API key de OMDb:

```text
https://www.omdbapi.com/apikey.aspx
```

No debes subir la API key a GitHub ni pegarla directamente en el código.

Debe configurarse como variable de entorno en AWS Lambda:

```text
OMDB_API_KEY = tu_api_key_real
```

El plan gratuito de OMDb permite realizar consultas suficientes para la práctica.

## Ejecución del scraper por línea de comandos

El archivo `imdb_scraper.py` cumple el requisito de poder ejecutarse directamente desde terminal.

Desde la carpeta `alexa_skill_def/`:


## Crear el ZIP de Lambda

Desde la carpeta `alexa_skill_def/`:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Comprueba que los archivos principales no tienen errores de sintaxis:

```bash
python -m py_compile lambda_function.py imdb_scraper.py cache.py
```

Genera el paquete para AWS Lambda:

```bash
bash deploy_lambda.sh
```

Esto genera:

```text
lambda_package.zip
```

Ese es el archivo que se debe subir a AWS Lambda.

## Configuración en AWS Lambda

En AWS Lambda, crea o edita la función:

```text
Nombre: CineInteligente
Runtime: Python 3.11
Handler: lambda_function.handler
Memory: 512 MB
Timeout: 20 seconds
Trigger: Alexa / Kit de habilidades de Alexa
```

Sube el ZIP en:

```text
Code -> Upload from -> .zip file
```

Archivo a subir:

```text
lambda_package.zip
```

Configura las variables de entorno:

```text
OMDB_API_KEY = tu_api_key_real
USE_DYNAMO = false
CACHE_TTL_DAYS = 7
```

## Diseño de la caché

La caché evita llamadas repetidas a OMDb para la misma película.

Flujo de primera consulta:

```text
Usuario pregunta por "Inception"
        |
        v
cache.get_cached("Inception") devuelve None
        |
        v
imdb_scraper.get_movie_info("Inception") consulta OMDb
        |
        v
cache.set_cached("Inception", datos)
        |
        v
Alexa responde
```

Flujo de segunda consulta:

```text
Usuario vuelve a preguntar por "Inception"
        |
        v
cache.get_cached("Inception") devuelve datos
        |
        v
No se llama a OMDb
        |
        v
Alexa responde directamente
```

La normalización de claves permite que variantes como:

```text
El Padrino
el padrino
padrino
```

puedan apuntar a la misma entrada de caché.

## Decisiones de diseño

### Uso de OMDb en lugar de scraping directo de IMDb

IMDb bloquea con frecuencia el scraping automatizado. OMDb ofrece una API más estable para obtener datos de películas.

Esto hace que el despliegue en AWS Lambda sea más fiable y evita que la práctica dependa de cambios en el HTML de IMDb.

### Caché en memoria y DynamoDB opcional

La caché en memoria es suficiente para la práctica, porque una Lambda puede mantenerse caliente durante varias invocaciones.

DynamoDB queda como opción adicional para persistir la caché entre invocaciones frías.

### Uso de sesión en Alexa

La skill guarda la última película mencionada en la sesión.

Esto permite que el usuario no tenga que repetir siempre el título.

Ejemplo:

```text
Usuario: quiero preguntar por Inception
Usuario: cuánto dura
Usuario: quién la dirigió
Usuario: cuál es su nota
```

Todas esas preguntas usan la película guardada en sesión.

## Errores frecuentes

### Falta `OMDB_API_KEY`

Error típico:

```text
Falta OMDB_API_KEY
```

Solución:

```text
AWS Lambda -> Configuration -> Environment variables
```

Añade:

```text
OMDB_API_KEY = tu_api_key_real
```

### `Unable to import module`

Causas posibles:

```text
Handler mal configurado
ZIP mal empaquetado
Dependencias no incluidas
```

Comprueba que el handler sea:

```text
lambda_function.handler
```

y que hayas subido:

```text
lambda_package.zip
```

no solo los archivos `.py`.

### `No module named ask_sdk_core`

Significa que subiste solo los `.py` o que el ZIP no contiene las dependencias.

Solución:

```bash
pip install -r requirements.txt
bash deploy_lambda.sh
```

Luego vuelve a subir:

```text
lambda_package.zip
```

### La skill no entiende las frases

Revisa:

```text
Alexa Developer Console -> Build -> Interaction Model -> JSON Editor
```

Asegúrate de que has pegado `interactionModel.json`, guardado y reconstruido el modelo:

```text
Save Model
Build Skill
```

### La Lambda falla durante la ejecución

Revisa CloudWatch Logs:

```text
AWS Lambda -> CineInteligente -> Monitor -> View CloudWatch logs
```
